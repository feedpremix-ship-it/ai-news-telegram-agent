# ИИ Новости | Нейросети — бесплатный Telegram-агент

Агент проверяет RSS-ленты каждые 30 минут (workflow запускается раз в 5 минут для команд управления), отбирает материалы не старше 72 часов, переводит заголовок и описание на русский, публикует максимум одну новость за цикл и не повторяет материал 7 дней.

## Что важно знать

- Это бесплатная схема на GitHub Actions, а не постоянно работающий сервер. Расписание может задерживаться; 24/7 без гарантированных задержек на бесплатном тарифе обещать нельзя.
- Чтобы стандартные GitHub-hosted runners были бесплатны, используйте публичный репозиторий. Код будет публичным; токены храните только в GitHub Secrets.
- Перевод выполняется через неофициальный интерфейс Google Translate через библиотеку `deep-translator`. Он бесплатен, но может временно ограничиваться или измениться. Если перевод недоступен, агент оставляет оригинальный текст.
- Отбор новостей эвристический, а не экспертная проверка фактов. Слухи маркируются, реклама отфильтровывается по словам, но это не абсолютная гарантия. Проверяйте логи и качество публикаций в первые дни.
- Источники RSS иногда меняют адреса или формат; если часть лент сломается, агент сообщит об этом администратору при нескольких ошибках.

## 1. Создайте Telegram-бота

1. В Telegram откройте `@BotFather`.
2. Отправьте `/newbot`, задайте имя и username.
3. Скопируйте токен. Никому его не отправляйте и не публикуйте.
4. Создайте канал, например `ИИ Новости | Нейросети`. Видимость можно выбрать позже; для публичного канала задайте уникальную ссылку.
5. Добавьте бота в администраторы канала и разрешите публикацию сообщений.
6. Чтобы получить свой chat ID для уведомлений: откройте бота в личном чате, нажмите Start. После первого запуска workflow команда `/status` ответит в личном чате. Для получения ID можно временно написать боту сообщение и открыть `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` в браузере, затем найти `message.chat.id`. Не публикуйте URL с токеном и после проверки закройте страницу.

## 2. Создайте репозиторий GitHub

1. Войдите на https://github.com/ и нажмите **New repository**.
2. Назовите репозиторий `ai-news-telegram-agent`.
3. Выберите **Public** (это важно для бесплатных стандартных runners) и создайте репозиторий.
4. Загрузите содержимое этой папки, сохраняя структуру каталогов. Самый простой путь: распаковать ZIP на компьютере, на странице репозитория нажать **Add file → Upload files**, перетащить файлы и папки и сделать commit.
5. Проверьте, что файл `.github/workflows/news-agent.yml` загружен.

## 3. Добавьте секреты

В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret**. Создайте три секрета:

- `BOT_TOKEN` — токен от BotFather.
- `CHANNEL_ID` — `@username_канала` для публичного канала или числовой ID канала для приватного. Бот должен быть администратором.
- `ADMIN_CHAT_ID` — ваш личный Telegram chat ID, только цифры. Напишите боту `/start` прежде чем ждать уведомления. Если не знаете свой ID, временно откройте `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` после сообщения боту и найдите `message.chat.id`. Не публикуйте URL с токеном.

Для приватного канала: добавьте бота администратором, включите workflow и опубликуйте тестовое сообщение в канале. При первом обнаружении публикации бот отправит `ADMIN_CHAT_ID` числовой ID канала. Укажите его в секрете `CHANNEL_ID`. Для канала с публичным username проще использовать `@username`.

Никогда не вставляйте токен прямо в `main.py` или в файл README.

## 4. Включите Actions и запустите тест

1. Откройте вкладку **Actions** репозитория и включите workflows, если GitHub предложит.
2. Выберите workflow **AI News Agent** → **Run workflow**.
3. Откройте запуск и посмотрите логи. Ошибка `BOT_TOKEN не задан` означает, что секрет не создан или назван неправильно.
4. Убедитесь, что бот может публиковать в канал.
5. Напишите боту в личном чате `/status`, `/pause` или `/resume`. Команды обрабатываются при следующем запуске workflow, обычно в пределах нескольких минут, но расписание может задерживаться.

## Команды

- `/status` — состояние, время последней проверки и число публикаций.
- `/pause` — остановить публикации.
- `/resume` — возобновить публикации.
- `/start` — список команд.

Команды принимаются от `ADMIN_CHAT_ID`, если он задан. Из-за особенностей планировщика это не мгновенный интерактивный бот.

## Как работает отбор

- проверяются RSS-источники, указанные в `FEEDS` в `main.py`;
- берутся публикации за последние 72 часа;
- проверяются домены, дата, URL, ключевые слова и признаки рекламы;
- приоритет получают официальные источники и свежие материалы;
- публикуется не более одной новости за цикл;
- идентификаторы опубликованных новостей сохраняются 7 дней;
- если подходящей новости нет, ничего не публикуется.

## Резервная копия и изменение источников

Скачивайте репозиторий как ZIP время от времени. Чтобы добавить RSS-источник, добавьте пару `('Название', 'RSS_URL')` в список `FEEDS` в `main.py`. Сначала проверьте RSS-адрес в браузере. Удалять источники можно из того же списка.

## Устранение проблем

- **Нет публикаций:** это может означать, что нет подходящих свежих новостей. Запустите workflow вручную и изучите логи.
- **Бот не публикует:** проверьте, что он администратор канала и у него есть право отправлять сообщения; проверьте `CHANNEL_ID`.
- **Перевод не сработал:** публикация может остаться на английском; это ограничение бесплатного неофициального переводчика.
- **Ошибка RSS:** лента могла поменять URL или формат; замените её в `FEEDS`.
- **Workflow не запускается:** проверьте вкладку Actions и уведомления GitHub. GitHub может задерживать расписание; бесплатный режим не является SLA.

## Более надёжный вариант 24/7

Если вам нужен настоящий постоянно работающий процесс и более быстрая обработка команд, перенесите тот же `main.py` на VM Oracle Cloud Always Free и запускайте как `systemd` service. Бесплатные ресурсы зависят от региона/доступности, а создание VM сложнее; внимательно выбирайте только ресурсы с пометкой Always Free и не подключайте платные ресурсы без проверки.

## Локальный тест на Windows 10/11 (необязательно)

Облачный запуск не требует, чтобы ваш компьютер был включён. Для проверки кода локально:

1. Установите Python 3.12 с https://www.python.org/downloads/windows/ и при установке отметьте **Add python.exe to PATH**.
2. Распакуйте ZIP, откройте папку `ai_news_agent`, щёлкните по адресной строке Проводника, введите `powershell` и нажмите Enter.
3. Выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

4. Перед локальным запуском задайте переменные в текущем окне PowerShell (подставьте свои значения):

```powershell
$env:BOT_TOKEN = "ТОКЕН_ОТ_BOTFATHER"
$env:CHANNEL_ID = "@username_канала"
$env:ADMIN_CHAT_ID = "ВАШ_ЧИСЛОВОЙ_CHAT_ID"
python main.py
```

Для приватного канала вместо `@username_канала` используйте числовой ID, обычно начинающийся с `-100`. Не отправляйте токен в чаты и не сохраняйте его в файлах проекта. После теста закройте окно PowerShell, чтобы очистить временные переменные.
